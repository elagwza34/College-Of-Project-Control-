# College of Project Controls

## 1. Project Description
A premium, high-converting B2B education website for the College of Project Controls (under Kent Business College). Targets UK employers, HR teams, L&D managers, and project controls professionals. Offers fully funded apprenticeships (Level 3, 4, 6) alongside commercial routes. The site positions the offer as a complete professional development package — not just an apprenticeship.

Target audience: British employers, HR teams, L&D managers, project controls professionals, PMO professionals, planners, schedulers, cost engineers, risk managers, project managers, self-employed professionals, and career changers.
