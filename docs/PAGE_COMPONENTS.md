# تعديل سيكشن في الموقع

ابدأ من [فهرس الصفحات والسيكشنز](../frontend/src/pages/README.md)، أو افتح مباشرة:

```text
frontend/src/pages/
  home/
    page.tsx
    README.md
    components/
      ProfessionalProgrammes.tsx
      FundingAndCosts.tsx
      ApprenticeshipEligibility.tsx
  knowledge-hub/
    what-is-pcp-apprenticeship/
      page.tsx
      README.md
      components/
        FundingGuides.tsx
        QuickSummary.tsx
        ProgrammeStructure.tsx
```

اسم الملف يتبع الليبل الظاهر في السيكشن بصيغة `PascalCase`. لو مفيش ليبل، نستخدم العنوان. الأقسام ذات العناوين المتغيرة، مثل نتائج البحث وتفاصيل المقالات، تستخدم اسمًا يوضح وظيفتها.

- `page.tsx`: ترتيب السيكشنز، وحالة الصفحة أو تحميل البيانات الذي تحتاجه عدة سيكشنز.
- `components/`: كمبوننت مستقل لكل سيكشن، والكمبوننتس الصغيرة المساعدة له.
- `README.md`: خريطة من الليبل أو العنوان إلى الملف، مع روابط التنفيذ المشترك ومصادر البيانات.
- ملفات `sectionData.ts` و`programmeData.ts` ونظائرها: النصوص والقوائم والإعدادات التي تستخدمها السيكشنز.

## السيكشنز المشتركة

التمويل والأهلية وIPC وغيرها لها مداخل بأسمائها داخل مجلد الصفحة. هذه الملفات تستدعي التنفيذ المشترك في `src/components/feature/` وتحدد إعدادات الصفحة. تعديل المدخل المحلي يخص الصفحة، بينما تعديل التنفيذ المشترك ينعكس على كل الصفحات التي تستخدمه. الاستيراد في أول الملف ودليل الصفحة يوضحان مكان التنفيذ.

الهيدر العام والفوتر يظلان مشتركين. المحتوى القادم من لوحة التحكم يظل مرتبطًا بمصادره الحالية؛ إعادة التنظيم لا تنقل بياناته إلى نسخ ثابتة في الملفات.

## إضافة سيكشن أو تغيير اسمه

1. أنشئ الملف داخل `components/` باسم الليبل، واجعل اسم الكمبوننت المصدر مطابقًا لاسم الملف.
2. استورده في `page.tsx` وضعه في ترتيب العرض المطلوب. احتفظ بالـIDs الموجودة حتى تظل روابط التنقل تعمل.
3. مرر الحالة المشتركة والأحداث كـprops، واترك الحالة التي تخص سيكشنًا واحدًا داخله.
4. حدّث الفهرس وشغّل الفحوص من مجلد `frontend`:

```powershell
npm.cmd run sections:index
npm.cmd run test:sections
npm.cmd run type-check
npm.cmd run lint
npm.cmd run build
```

فحص `test:sections` يتحقق من مجلدات الصفحات وأدلتها، ومن فصل السيكشنز عن ملفات الدخول، ومن تطابق أسماء الملفات مع الكمبوننتس.
